# Aprendizado — Golden Set condicional à sobreposição real

- **Decisão tributária:** Positivo, Negativo e Bloqueado são obrigatórios em toda revisão; Ambíguo só é obrigatório quando o Rulebook contém duas ou mais regras com a mesma chave Evento + Código normalizado.
- **Motivo:** não criar regra fiscal artificial apenas para satisfazer um teste.
- **Garantia:** a capacidade do motor de detectar múltiplas regras e retornar Ambíguo, sem escolha automática, permanece em regressão sistêmica permanente.
- **Aplicação:** TASK-2-006, SKIP 0.0.170; backend e UI usam o mesmo cálculo.
