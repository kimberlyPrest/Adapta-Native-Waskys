# Aprendizado — gate de aprovação e caso Ambíguo

- **Sinal:** o golden set exige um caso Ambíguo para provar sobreposição sem escolha silenciosa.
- **Falha evitada:** bloquear aprovação sempre que o relatório contém conflitos tornaria impossível aprovar um golden set correto com 4/4 casos, porque o conflito é justamente o resultado esperado do caso Ambíguo.
- **Orientação:** o gate exige 100% dos casos com resultado observado igual ao esperado. Conflitos continuam visíveis; a aprovação motivada do responsável tributário registra a decisão, sem selecionar automaticamente uma das regras conflitantes.
- **Aplicação:** TASK-2-006, SKIP 0.0.166.
